## 1. What cyber security is

**Cybersecurity is the process of protecting networks, systems, applications and digital assets from unauthorized access, cyberattacks, malware and data breaches.**

It ensures the **confidentiality, integrity and availability (CIA)** of information while supporting secure and sustainable digital infrastructure.

What it does, concretely:

- **Protects sensitive data** using encryption, authentication and access control.
- **Secures networks and systems** against malware, ransomware and cyber threats.
- **Supports safe digital transformation** through secure cloud and IT infrastructure.
- **Reduces downtime**, resource misuse and operational risks caused by attacks.
- **Enhances the reliability and resilience** of modern digital technologies.

## 2. Core pillars — the CIA triad

Cybersecurity is based on **three core principles** that help protect information and systems.

| Pillar | Meaning | One-liner |
|---|---|---|
| **Confidentiality** | Ensures that sensitive information is accessible **only to authorized users**. | Prevents unauthorized access |
| **Integrity** | Protects data from **unauthorized modification** and maintains its accuracy. | Ensures data accuracy |
| **Availability** | Ensures systems, services and data **remain accessible whenever needed**. | Ensures system access |

> This is the same triad introduced in [Network Security Fundamentals](../module-1/01-network-security-fundamentals.md#2-fundamental-security-objectives-the-cia-triad), where it is developed further with the sub-concepts of privacy, data vs. system integrity, and the additional requirements of authenticity and accountability.

## 3. Types of cyber security

There are **seven types**, each with its own focus and toolset.

| # | Type | Protects | How |
|---|---|---|---|
| 1 | **Network Security** | Network connections and data | Protects computer networks from unauthorized access, malware and cyberattacks using **firewalls, VPNs, intrusion detection systems and network monitoring tools** |
| 2 | **Application Security** | Software from attacks | Secures software and mobile applications through **secure coding practices, regular updates, vulnerability testing and security patches** |
| 3 | **Information or Data Security** | Sensitive information | Protects data from unauthorized access, modification or loss using **encryption, access controls, data classification and backup strategies** |
| 4 | **Cloud Security** | Online stored data | Secures cloud-based data, applications and infrastructure through **identity management, encryption, compliance controls and secure configurations** |
| 5 | **Endpoint Security** | User devices and systems | Protects computers, smartphones, servers and IoT devices using **antivirus software, device encryption and regular system updates** |
| 6 | **Operational Security** | Organizational assets | Security **policies, access management, risk assessment, employee awareness programs and incident response procedures** |
| 7 | **Internet of Things (IoT) Security** | Smart connected devices | Protects smart home systems, wearables and industrial sensors through **authentication, encryption and regular firmware updates** |

## 4. Major cyber security threats and attacks

Cybersecurity threats target systems, networks and data using various attack techniques. The most common:

| Threat | One-liner | Detail |
|---|---|---|
| **Malware attacks** | Harmful software damages system | Harmful software such as **viruses, trojans, ransomware and spyware** that can damage systems or steal data |
| **Phishing & spear phishing** | Fake messages steal information | Use **fake emails, messages or websites** to trick users into revealing sensitive information |
| **Ransomware attacks** | Data locked for money | **Encrypts files and demands payment** to restore access, often targeting businesses and organizations |
| **DDoS attacks** | Too much traffic attack | **Distributed Denial-of-Service** attacks overwhelm servers with excessive traffic, making services unavailable |
| **SQL injection** | Database commands misused | A critical vulnerability where an attacker **manipulates a backend database by injecting malicious SQL code** into vulnerable user-input fields |
| **Zero-day exploits** | Unknown security weakness exploited | Targets a software, hardware or firmware vulnerability **completely unknown to the developer or vendor**. "Zero-day" signifies the responsible party has had **zero days to create a patch** or mitigation |

> Malware, DoS/DDoS and the network-level attack families are developed in detail in [Malware and Back Doors](03-malware-and-backdoors.md), [DoS, Spoofing and MITM](04-dos-spoofing-and-mitm.md) and [Protocol, DNS, ARP and TCP/IP Attacks](05-protocol-dns-arp-tcp-attacks.md).

## 5. Emerging trends in cyber security

Cybersecurity is constantly evolving to address new threats and technologies.

- **Rise of AI and machine learning** — AI-powered tools help detect, analyze and respond to cyber threats more quickly and accurately.
- **Rising ransomware attacks** — ransomware attacks continue to grow, making **regular backups** and strong security measures essential.
- **Cloud security** — as cloud adoption increases, organizations focus on securing cloud data and applications.
- **IoT security challenges** — connected devices create new security risks, requiring stronger protection and regular updates.
- **Zero Trust security** — Zero Trust **verifies every user and device before granting access**, reducing security risks.

## 6. Challenges of cyber security

| Challenge | Problem | Response |
|---|---|---|
| **Evolving threats** | Attackers constantly create new methods | Keep systems updated and monitor regularly |
| **Limited budgets** | Security tools are costly | Prioritize critical assets and use cost-effective solutions |
| **Insider threats** | Misuse of access | Enforce strict access controls and monitor user activity |
| **Complex technology** | Cloud, IoT and hybrid systems increase complexity | Simplify systems and conduct regular security audits |
